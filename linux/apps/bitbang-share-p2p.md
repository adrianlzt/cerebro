https://github.com/richlegrand/bitbang-cli

Turn your machine into a URL. Peer-to-peer over WebRTC -- no account, no client to install, no port forwarding.

BitBang CLI is a single static binary remote-access multitool: open an interactive shell, browse and transfer files, and access web apps on the remote machine's network from any browser, no port forwarding, no configuring, and no account.

Lograr un acceso sencillo a un server remoto.
Acceder por ssh, ficheros (download/upload) o http proxy.
